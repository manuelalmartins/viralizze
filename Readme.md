# Viralizze

Bem-vindo ao **Viralizze**! Este projeto é uma plataforma para divulgação de vagas, onde usuários podem postar oportunidades, candidatar-se, criar posts, trocar mensagens, acompanhar candidaturas e gerenciar o status de cada candidatura.

## Sobre

O Viralizze é uma solução voltada para facilitar o processo de recrutamento e interação entre candidatos e recrutadores. Permite a publicação de vagas, candidatura, comunicação direta e acompanhamento do status das candidaturas.

## Recursos

- Publicação de vagas
- Candidatura a oportunidades
- Criação de posts e interação entre usuários
- Troca de mensagens privadas
- Visualização e gerenciamento de candidaturas
- Aceitação ou rejeição de candidatos
- Definição e atualização do status das candidaturas

## Instalação

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/manuelalmartins/viralizze.git
cd viralizze
npm install
```

## Como usar

Para iniciar o projeto localmente:

```bash
npm start
```

Acesse `http://localhost:3000` no seu navegador para utilizar a plataforma.
